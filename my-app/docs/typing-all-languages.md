# 全言語の待機画面対応

既存変更：`src/app/typing/[language]/page.tsx`

Java・Python・Cをの3言語を同じ待機画面経由に統一しました。
開始ボタンを押してからゲームが始まり、結果から各言語の待機画面に戻れます。
ランキング・本人履歴は選択した言語で絞り込みます。

Firestoreの単発取得・5分キャッシュ・取得件数制限・1プレイ1件保存を共通利用します。
各言語を初めて開くと、その言語のランキングと履歴を取得します。
他の言語のデータを先読みする処理や、新しい書き込みは追加していません。
既存の複合インデックスは言語の値によらず利用できるため、この変更によるFirebase側の追加設定はありません。

## 動作確認

1. `/typing`からJava・Python・Cをそれぞれ選択し、対応する言語名の待機画面が出ること。
2. 待機中はゲームのタイマーが動かず、結果も保存されないこと。
3. スタート後は選択言語の問題が出ること。
4. 終了・保存後に「待機画面へ戻る」で同じ言語の画面に戻り、本人履歴に記録が反映されること。
5. 言語を切り替えてもランキング・履歴・問題が混ざらないこと。
6. 5分以内の同一言語への往復でキャッシュを再利用すること。
7. `/typing/unknown`や`/typing/toString`は404になること。

コミット案：`feat: 全言語にタイピング待機画面を適用`

JavaScriptのタイピング選択肢・問題データは削除済みです。/typing/javascript は404になります。
