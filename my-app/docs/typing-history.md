# 本人のプレイ履歴

Java待機画面のランキングの下に本人のJavaの履歴を新しい順で20件表示します。
表示項目：日時（日本時間）、言語、スコア、ランク、問題数、ミス数、正確率。
待機画面に戻ると再取得します。ゲーム中は購読を解除します。

## Firebase側の設定

現在公開済みのランキング用ルールで読み取れます。ルールの追加変更は不要です。
履歴用に次の複合インデックスをFirestore Database → インデックスで追加してください。

- コレクションID：`typingScores`
- `userId`：昇順
- `language`：昇順
- `createdAt`：降順
- クエリスコープ：コレクション

不足時はブラウザコンソールのFirebaseエラーにある作成リンクからも追加できます。
作成が有効になるまで待ち、履歴の「再読み込み」を押してください。

## 動作確認

1. Java待機画面で自分のJava履歴だけが新しい順に表示されること。
2. プレイして保存後、待機画面に戻ると新しい履歴が増えること。
3. 別アカウントでログインするとそのアカウントの履歴だけになること。
4. 記録なしの場合は案内が出ること。
5. 履歴が取得できなくてもゲーム開始・ランキングが使えること。
6. 戻るボタン・再プレイ・保存が引き続き動くこと。
