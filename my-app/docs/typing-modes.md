# タイピングの時間モード

- 通常モード: 120秒、`mode: "standard"`
- 長時間モード: 300秒、`mode: "long"`
- 保存先は既存の `typingScores`。言語とモードで絞ってスコア上位10件を取得する。
- モード未設定の既存記録はランキングの対象外。履歴では通常モードとして表示する。既存記録をランキングにも含める場合は、バックアップ後に管理者環境から `mode: "standard"` を補完する。
- 問題をすべて入力した場合は制限時間前でも終了する。

## Firebase側の設定

モード別ランキングには `firestore.indexes.json` の複合インデックスが必要。
Firebaseコンソールで `typingScores` に `language` 昇順、`mode` 昇順、`score` 降順のインデックスを追加する。
取得エラーに含まれる作成リンクからも追加できる。既存インデックスは削除しない。
このリポジトリにはFirebaseの接続設定・ルールがないため、インデックスは未デプロイ。
本番ルールで保存フィールドを制限している場合は `mode` の追加を許可する必要がある。

## 動作確認

1. 待機画面で通常／長時間を選ぶと、制限時間とランキング見出しが切り替わる。
2. 各モードで開始し、タイマーが120／300秒から減ることを確認する。
3. 終了後の記録に選択した `mode` が入り、同じモードのランキングだけに反映される。
4. もう一度遊ぶと同じ制限時間に戻る。
5. 履歴に各記録のモードが表示される。
